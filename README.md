# 풍력 에너지 도구 (wind-energy-tool)

해상풍력 단지의 연간 발전량을 계산하고 보고서·도면을 만드는 웹 도구입니다.
설치 없이 브라우저에서 `index.html`을 열어 씁니다(파일 읽기용 라이브러리는 `lib/`에 들어 있음).

## 화면 구성

1 풍황자료 → 2 터빈 → 3 구역 → 4 배치·후류 → 5 발전량 → 6 보고서

| 탭 | 하는 일 |
|---|---|
| 1 풍황자료 | 평가 보고서·Windographer PDF, 라이다 .sta, CSV/TXT 시계열을 읽어 대표 풍황(허브높이 방향별 Weibull) 지정, 측정 기간, 장기 공기밀도(기상청 관측소 평년값) |
| 2 터빈 | 출력곡선·Ct 곡선, 기본 제공 터빈(두산 DS205-10MW·유니슨 U210-10MW — 공개 사양 추정), 터빈 파일(.json) 가져오기·내보내기, 터빈 비교, 제조사 요청 항목 점검표 |
| 3 구역 | 사업 구역 경계, 제외 구역(이격 거리), 풍속 기준점, DXF·좌표 붙여넣기 |
| 4 배치·후류 | 터빈 배치, 후류 모델(Jensen·TurbOPark·가우스), 간격 검사, 케이블 길이, 배치 최적화, 허가 설비용량(±10%·단지 출력 상한·기당 출력 제한), 터빈별 비교, DXF·PDF 도면 |
| 5 발전량 | 손실(조건별 기본값), 불확도(TR6·IEC·MEASNET), P50·P75·P90 |
| 6 보고서 | 발전량 평가 보고서 구성의 한글(HWPX)·PDF 보고서 |

## 파일

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 틀·스타일 |
| `app.js` | 화면·계산 흐름·보고서·도면 |
| `wind-core.js` | 계산 핵심(PDF 표 읽기, Weibull, 발전량, 후류, 좌표 변환, 기본 터빈) |
| `hwpx.js`, `hwpx-tpl.js` | 한글(HWPX) 문서 만들기 |
| `lib/` | JSZip, pdf.js (외부 라이브러리) |
| `docs/` | 적용 사항 기록 |

## 검증

상용 발전량 평가 보고서 결과와 비교해 계산을 확인했습니다(총발전량 차이 약 2%, 후류 손실 차이 0.2%p 이내).

## 터빈 자료

제조사 출력곡선은 공개판에 넣지 않습니다. 받은 곡선은 "터빈 파일 가져오기"로 불러와 쓰세요. 해상풍력발전기 기초 설계도구와 같은 터빈 파일(gbs-tool-turbine)을 씁니다.

## 주의

- **비공개 저장소로 유지하세요.** 기본 터빈 곡선 등에 평가 보고서 수치가 들어 있습니다.
- 원본 보고서 PDF·측정 자료는 저장소에 올리지 않습니다(`.gitignore`).
- 두산·유니슨 곡선은 공개 사양으로 만든 추정치입니다. 보고서용은 제조사 곡선으로 바꿔야 합니다.
